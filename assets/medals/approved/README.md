# Godkjente trykkfiler

Bare filer med kontrollert frilegging, hele ytterkanter, tilstrekkelig native oppløsning ved faktisk størrelse og kildebundet godkjenning i `data/badges.json` skal ligge her. Originaler bevares i `../originals/`, og uavklarte bearbeidelser i `../review/`. En fil er ikke godkjent av at den ligger i bildebiblioteket.
